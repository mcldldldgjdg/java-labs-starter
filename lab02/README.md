# Лабораторная работа №2 — Классы и инкапсуляция

## Цель работы

Изучить создание собственных классов Java, использование конструкторов, инкапсуляцию полей и проверку корректности данных.

## 1. Подготовительная часть — BankAccount

Реализован класс банковского счёта с приватным полем `balance`.

**Инварианты:**
- Баланс не может быть отрицательным.
- Начальный баланс должен быть не меньше нуля.
- Пополнение допускается только на положительную сумму.
- Снятие допускается только на положительную сумму.
- Нельзя снять больше средств, чем имеется на счёте.
- Переполнение типа `int` запрещено.
- Баланс изменяется только через `deposit()` и `withdraw()`.

Реализованы методы `deposit()`, `withdraw()` и `getBalance()`.

## 2. Основное задание — ProjectTask

Создан класс для хранения и управления задачами программного проекта.

**Инварианты:**
- Идентификатор задачи не может быть `null` или пустым.
- Название задачи не может быть `null` или пустым.
- Статус задачи не может быть `null`.
- Оценка трудоёмкости не может быть отрицательной.
- Идентификатор и название не изменяются после создания.
- Статус изменяется через `changeStatus()`.
- Трудоёмкость увеличивается только на положительное количество часов.
- Переполнение типа `int` запрещено.

Используется перечисление `TaskStatus` со значениями `TODO`, `IN_PROGRESS`, `DONE`.

Реализованы методы изменения статуса, определения завершённости и увеличения трудоёмкости задачи.

## 3. Дополнительное задание — Identifier

Создан неизменяемый класс `Identifier`.

Поле `value` объявлено как `private final`, а сам класс — `final`.

Идентификатор является объектом-значением: два объекта с одинаковым текстовым идентификатором считаются равными независимо от того, являются ли они одним объектом в памяти.

Для сравнения реализованы `equals()` и `hashCode()`.

## 4. Тестирование

Для проверки классов разработаны автоматические тесты с использованием JUnit Jupiter.

Тесты проверяют успешные операции, некорректные значения и сохранение правильного состояния объекта после неудачных операций.

Запуск из корневой папки проекта:

```powershell
.\mvnw.cmd -pl lab02 clean test
```

## Вывод

В ходе лабораторной работы изучены принципы объектно-ориентированного программирования на Java, создание классов, использование модификаторов доступа `private`, `public`, `final`, а также инкапсуляция состояния и проверка инвариантов. Реализованы классы с контролируемым изменением состояния и автоматические тесты для проверки их корректности.
