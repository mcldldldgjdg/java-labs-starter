Условие: [`assignments/lab03-polymorphism.md`](../assignments/lab03-polymorphism.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab03 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab03 test`.

Основной код размещайте в `src/main/java/edu/course/lab03/`, тесты — в `src/test/java/edu/course/lab03/`. В начале каждого Java-файла укажите `package edu.course.lab03;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.


## Реализованное задание

### Подготовительная часть

Создан интерфейс DiscountPolicy и две реализации:

- NoDiscount — цена не изменяется.
- PercentDiscount — применяет процентную скидку.

Процент скидки находится в диапазоне от 0 до 100.
Цена должна быть неотрицательной и конечной.

PriceCalculator получает реализацию интерфейса
через конструктор.

### Основное задание

Создан интерфейс PriorityPolicy.

Реализованы две стратегии:

- EffortPriorityPolicy — приоритет выше у задач
  с меньшей оценкой трудоемкости.
- StatusPriorityPolicy — приоритет определяется
  статусом задачи.

Порядок статусов по приоритету:

1. IN_PROGRESS
2. TODO
3. DONE

При одинаковом приоритете выбирается первая задача.

TaskPrioritizer зависит от интерфейса PriorityPolicy,
а не от конкретных классов.

Класс ProjectTask хранит данные задачи и не
позволяет изменять их напрямую.

### Дополнительная часть

Добавлена третья стратегия LargeEffortPriorityPolicy.

Она отдает предпочтение наиболее трудоемким задачам.

Для подключения новой стратегии не потребовалось
изменять TaskPrioritizer.

### Полиморфизм

Полиморфизм позволяет использовать разные реализации
одного интерфейса через общий тип ссылки.

Метод calculatePriority() вызывается у фактического
объекта стратегии.

### Тестирование

Написаны JUnit-тесты для всех стратегий,
проверки ограничений и замены реализаций.

Команда:

.\mvnw.cmd -pl lab03 clean test
