# Лабораторная работа 4: Контракты equals, hashCode и HashMap

Условие: [`assignments/lab04-hash-table.md`](../assignments/lab04-hash-table.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab04 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab04 test`.

Основной код размещайте в `src/main/java/edu/course/lab04/`, тесты — в `src/test/java/edu/course/lab04/`. В начале каждого Java-файла укажите `package edu.course.lab04;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.

## Реализованное задание

### Подготовительная часть

Создан неизменяемый класс Book.

Книги сравниваются по ISBN.
Переопределены equals() и hashCode().
Проверен поиск в HashMap по другому объекту
с тем же ISBN.

### Основная часть

Создан неизменяемый класс IssueId,
состоящий из кода проекта и номера задачи.

Равенство определяется обоими полями.
Хеш-код вычисляется из тех же полей.

IssueRegistry использует HashMap<IssueId, ProjectTask>.

Реализованы операции:
- добавление и замена;
- получение;
- удаление;
- проверка наличия;
- получение размера.

### Эксперименты

Проверены логически равные ключи,
замена значений и коллизии хеш-кодов.

Отдельным тестом показана проблема
изменяемого ключа в HashMap.

### Дополнительная часть

Создана ChainedHashTable для IssueId и ProjectTask.

Коллизии разрешаются через цепочки записей.
Дженерики в собственной таблице не используются.

### Тестирование

Команда:

.\mvnw.cmd -pl lab04 clean test
